# Wan 3.0 API — from $0.038/s (480p)

**Alibaba Wan 3.0 is live on [ArgoLink](https://argolink.io/gh-wan-3-0-api)**: $0.038/s at 480p, $0.075/s at 720p and $0.15/s at 1080p, 24–25% below Alibaba Cloud's international list price. One model ID takes a prompt, a first frame, a first and last frame, up to 20 reference images, clips and sounds, or a clip to rewrite, and returns a 2–30 second video with a soundtrack you can switch off.

[Wan 3.0 model page →](https://argolink.io/en/models/wan-3) · [Prices](#price-per-second) · [Install](#install) · [Modes](#the-five-modes) · [API surface](#api-surface) · [MCP server](#mcp-server) · [FAQ](#faq)

`wan3` is a dependency-free Python package for that model: one `Shot` describes a request and refuses anything the API would reject, `Wan3` submits it, polls it and saves the MP4, `python -m wan3` does the same from a shell, and `wan3-mcp` hands it to Claude Code, Cursor or Codex as MCP tools.

## Specs

| | `wan-3` |
|---|---|
| Endpoints | `POST /v1/videos/generations`, `GET /v1/videos/{request_id}`, `GET /v1/videos/{request_id}/content`, `POST /v1/media/uploads` |
| Duration | 2–30 s, whole seconds (default 5) |
| Resolution | 480p · 720p · 1080p (default 720p) |
| Aspect ratio | 21:9 · 16:9 · 4:3 · 1:1 · 3:4 · 9:16 · adaptive (default 16:9) |
| References | up to 10 images, 5 videos, 5 audio clips (20 in total); clips 1–15 s each, 15 s per kind; output + reference video ≤ 30 s; audio may be the only reference |
| Video edit | `omni_reference_task_type: "edit"` rewrites a 1–15 s clip and keeps its length and ratio |
| Prompt | required in every mode, up to 20,000 characters |
| Seed | integer 0–4294967295; the same seed and request give the same video |
| Sound | generated by default; `generate_audio: false` for a silent MP4 |
| Not supported | `watermark: true`, `n` > 1 (400) |

## Install

```bash
git clone https://github.com/ingramwolfric6/wan-3-0-api
cd wan-3-0-api
pip install -e .            # the client has no dependencies (Python 3.9+)
pip install -e ".[mcp]"     # the MCP server needs Python 3.10+ and mcp 2.x
export WAN_API_KEY=...      # an ArgoLink key; WAN_BASE_URL overrides https://argolink.io/v1
```

## Quick start

```python
from wan3 import Shot, Wan3, price

client = Wan3()
shot = Shot(
    "A cinematic tracking shot of a red fox crossing a snowy forest at sunrise",
    duration=8, resolution="720p", aspect_ratio="16:9", seed=42,
)
print(shot.body())                      # the exact JSON that will be sent; raises on invalid input
job = client.run(shot, "fox.mp4", progress=lambda j: print(j["status"], j.get("progress")))
print(job["usage"], price(8, "720p"))   # billed seconds, $0.60
```

Or from the shell, where local files are uploaded for you:

```bash
python -m wan3 "Paper cranes take flight from a desk" --seconds 6 --tier 1080p --ratio 9:16
python -m wan3 "Make it snow" --edit street.mp4 --tier 480p --dry-run    # print the body, send nothing
```

## The five modes

| Mode | `Shot(...)` fields | Wire fields | Notes |
|---|---|---|---|
| Text | `prompt` | `prompt` | any of the seven ratios |
| First frame | `start_image` | `start_image` | `adaptive` (default here) follows the frame; a fixed ratio crops it |
| First + last frame | `start_image`, `end_image` | `start_image`, `end_image` | the last frame is adapted to the first frame's shape |
| Reference | `images`, `videos`, `audios` | `reference_images`, `reference_videos`, `reference_audios` | name them `@Image 1`, `@Video 1`, `@Audio 1`; audio-only is allowed |
| Edit | `edit=True`, `videos[0]` = the clip | `omni_reference_task_type: "edit"`, `reference_videos[0]` | 1–15 s source; up to 10 images, 4 more videos, 5 audio clips steer it; no duration or ratio |

Frames and references cannot share a request, and an edit cannot take frames.

```python
client.image_to_video("The bud opens into a peony", "https://example.com/bud.png", "peony.mp4",
                      end_image="https://example.com/peony.png", duration=5)
client.reference_to_video("The singer in @Image 1 performs @Audio 1 on a rooftop at dusk", "song.mp4",
                          images=["https://example.com/singer.png"], audios=["https://example.com/verse.mp3"],
                          duration=12)
client.edit_video("Swap the red car for a vintage bicycle; keep the camera move", client.upload("street.mp4"),
                  "street-edit.mp4", resolution="720p")
```

More in [`examples/`](./examples): [first + last frame](./examples/first_last_frame.py), [edit](./examples/edit_clip.py), [audio-only reference](./examples/audio_driven.py), [seed sweep](./examples/seed_sweep.py) and the [three curl calls](./examples/curl.sh).

### Uploading local files

`client.upload(path)` asks `POST /v1/media/uploads` for a free ticket, PUTs the bytes to the signed `upload_url` (valid 15 minutes, no bearer token) and returns the `media_url` (readable seven days). Accepted: JPEG or PNG up to 20 MiB, MP4 or MOV up to 100 MiB and 1–15 s, WAV or MP3 up to 15 MB and 1–15 s. A file outside those limits fails the job with `invalid_input` before generation, and nothing is charged.

## API surface

| Call | Purpose |
|---|---|
| `Shot(...).body()` | build and validate one request (mode, ratio, duration, tier, caps, seed, HTTPS) |
| `Wan3.submit(shot)` | `POST /videos/generations`, returns `request_id` |
| `Wan3.status(id)` / `Wan3.wait(id)` | one status read / poll until `done` (raises on `failed` or `expired`) |
| `Wan3.save(id, path)` | `GET /videos/{id}/content` to a file |
| `Wan3.upload(path)` | local file to `media_url` |
| `Wan3.run(shot, path)` | submit + wait + save |
| `text_to_video`, `image_to_video`, `reference_to_video`, `edit_video` | one-line wrappers around `run` |
| `price(seconds, tier, reference_video_seconds)` | cost at the rates above |

The status endpoint reports `pending` with `progress` 0–99 (and `estimated_seconds_remaining` once known), then `done` with `video.url` and `usage`, or `failed` / `expired` with an `error` object. Content requests answer 409 `job_video_not_ready` until the job is done.

## Billing

- Rate per output second for the tier, times the length.
- Reference videos add their seconds (the fractional part of the total is dropped): 5 s with a 2.4 s clip bills 7 s.
- An edit bills the edited clip twice, as output and as reference: a 6 s edit at 720p bills 12 s, $0.90.
- Reference images and audio cost nothing; neither do uploads, failed jobs or expired jobs.

## Wan 3.0 or Wan 3.0 Prime?

`wan-3-prime` is the faster lane: 4–30 s, 16:9 / 1:1 / 9:16 only, no frames, no edit, no seed, always with sound, at $0.051 / $0.11 / $0.21 per second. Choose `wan-3` for frames, edits, 21:9 or 4:3, silent output, repeatable seeds, audio-only references, 2–3 second clips or the lower price.

## MCP server

`wan3-mcp` (or `python -m wan3.mcp_server`) serves four stdio tools: `create_video`, `edit_video`, `check_video`, `fetch_video`. Validation errors come back as readable tool errors so the agent can correct its call.

```bash
# Claude Code
claude mcp add --transport stdio --env WAN_API_KEY=your-key wan-3 -- wan3-mcp
```

Cursor, in `.cursor/mcp.json`:

```json
{ "mcpServers": { "wan-3": { "command": "wan3-mcp", "env": { "WAN_API_KEY": "${env:WAN_API_KEY}" } } } }
```

```toml
# Codex: ~/.codex/config.toml
[mcp_servers.wan-3]
command = "wan3-mcp"
env_vars = ["WAN_API_KEY"]
```

## Endpoint compatibility

Requests go to `{WAN_BASE_URL}/videos/generations`, `/videos/{request_id}`, `/videos/{request_id}/content` and `/media/uploads`, all with `Authorization: Bearer`. Field names written for fal or OpenRouter (`image_url`, `image_urls`, `video_urls`, `audio_urls`, `frame_images`, `input_references`, `seconds`, `ratio`) are accepted by the endpoint too; `size` such as `1280x720` can replace `resolution` + `aspect_ratio`, except in an edit.

## FAQ

**Does Wan 3.0 support 1080p?**
Yes: 480p, 720p and 1080p, at $0.038, $0.075 and $0.15 per second here.

**What is the longest clip?**
30 seconds. With reference videos, the output plus their total length must stay within 30 s.

**Can I make a silent video?**
Yes, send `generate_audio: false` (`Shot(sound=False)`, `--silent`). The price is the same.

**How do I repeat a render?**
Send the same request with the same `seed` (0–4294967295).

**How much does editing a 10-second clip at 1080p cost?**
20 billed seconds × $0.15 = $3.00, because the clip counts as output and as reference.

**Can audio alone drive a Wan 3.0 video?**
Yes on `wan-3`. `wan-3-prime` needs an image or video next to the audio.
